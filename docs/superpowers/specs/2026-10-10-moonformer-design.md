# MoonFormer v0: recall through consequences

Build a working, inspectable experiment in the user-created MoonFormer repository, using the supplied original CrystalMoon files as the reference. Keep those files byte-for-byte unchanged. The ongoing webcam version is a separate project.

The central question is whether a past input can leave a persistent structural trace that can subsequently be distinguished by its effects on travelling signals. A scalar 2-D Swift–Hohenberg medium evolves slowly; a damped wave probes a snapshot of it. Density changes wave speed. A finite, discrete antipodal inversion maps waves to inner receivers. Reverse differentiation exposes which structural changes would affect a selected receiver reading.

The first experiment writes four families of geometric traces, removes all writing input, evolves the medium further, and fits a small readout only on training probe responses. Held-out seeds and geometric variants are separate. Erasure, donor-state substitution, and zero wave/structure coupling are mandatory controls. The input label and writing mask never enter the probe or classifier. Record actual results even when they fail. This is neither a semantic memory nor an LLM, and does not establish a brain mechanism, experience, or a new transformer architecture.

Deliver a dependency-free browser instrument showing the actual material, propagated wave, inner receivers, and signed local sensitivity. Users can write, wait, probe, erase, substitute a retained state, and export/import numerical memory. Reference files remain accessible. Document physical parameters, numerical approximations, causal limits, primary sources, and reproducible commands.

Success means a runnable mechanism with measured evidence and honest failure controls, not a guaranteed classification score. Populate the requested repository after verification. No unrelated repositories or site hosting changes.
