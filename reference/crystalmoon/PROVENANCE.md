# Original CrystalMoon reference

These two files are the original attachments supplied by Antti for MoonFormer on 2026-10-10, before the current CrystalMoon webcam/wall changes. They are copied without rewriting or line-ending conversion:

- `core.js` from the supplied `core.js`.
- `index.html` from the supplied `index(10).html`.

Open `index.html` through the local server for the original walkable 3-D world. It needs WebGL2 and floating-point render targets. This directory is a historical reference, not MoonFormer's new probe/learning implementation. The parent repository's MIT license applies.
